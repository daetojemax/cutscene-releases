# Cutscene releases

Downloads of **Cutscene** — clips from your streams. Get it at **[cutscene.tech](https://cutscene.tech)**.

- **Mac** (Apple silicon, macOS 12 or later): download the `.dmg` from the [latest release](../../releases/latest),
  open it and drag Cutscene to Applications. The app is signed and notarized by Apple.
- **Windows**: on the way.

This repository holds release files only. Support: see cutscene.tech.
